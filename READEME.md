# Calculadora de IMC Web 🧮

Uma aplicação web simples, leve e responsiva para calcular o Índice de Massa Corporal (IMC), desenvolvida com tecnologias web fundamentais (HTML, CSS e JavaScript puro).

---

## 🚀 Funcionalidades

- **Cálculo Instantâneo:** Insira seu peso e altura para obter o resultado na hora.
- **Classificação Completa:** Exibe a faixa de IMC correspondente (Abaixo do peso, Peso normal, Sobrepeso e Obesidade) baseada nos critérios da OMS.
- **Design Responsivo:** Adaptado para funcionar perfeitamente em computadores, tablets e smartphones.
- **Validação de Campos:** Evita erros de preenchimento caso o usuário deixe campos em branco ou insira valores inválidos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da página.
- **CSS3:** Estilização moderna, uso de Flexbox e variáveis para customização visual.
- **JavaScript (ES6+):** Lógica de cálculo, manipulação do DOM e tratamento de eventos.
